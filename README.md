# Superstore Sales & Demand Forecasting 📈

**Future Interns ML Task 1**  
A complete machine learning pipeline to predict future sales, analyze seasonal trends, and generate actionable business intelligence using the Superstore dataset.

---

## 🎯 Project Objective
The goal of this project is to predict future sales/demand based on historical data. Instead of just focusing on raw model accuracy, this project emphasizes **business-friendly presentation**. It translates machine learning metrics (like RMSE and R²) into real-world business decisions: inventory planning, safety stock buffering, and promotional timing.

## 🛠️ Tech Stack
*   **Python** (Pandas, NumPy) for Data Cleaning and Feature Engineering
*   **Scikit-Learn** for Machine Learning (Random Forest & Linear Regression)
*   **Matplotlib** for static, business-ready report generation
*   **HTML/CSS/JavaScript (Chart.js)** for an interactive web dashboard

## 🚀 How to Run the Project

**1. Run the Machine Learning Pipeline**  
This script cleans the data, engineers time-based features, trains the models, and generates the `forecast_data.json` file.
```bash
python sales_forecasting_1.py
```

**2. Generate the PDF and Matplotlib Charts**  
This script reads the JSON data and generates all the professional charts located in the `reports/` folder.
```bash
python visualize_matplotlib.py
```

**3. View the Interactive Dashboard**  
Start a local server to view the glassmorphic, interactive web dashboard.
```bash
python run_dashboard.py
```
*Then open `http://localhost:8000/dashboard.html` in your browser.*

## 💡 Key Business Insights

Based on the 6-month out-of-sample forecast generated by the **Random Forest Regressor** (which achieved an **84.1% R²** on cyclical categories like Furniture):

1.  **Peak Season (November):** Demand spikes to **1.82x** the monthly average. *Action: Build inventory 6 weeks prior to cover lead times.*
2.  **Slow Season (February):** Demand drops to **0.38x** the monthly average. *Action: Run promotional clearance campaigns to protect cash flow.*
3.  **Safety Stock:** The model's error (RMSE) was calculated to establish a strict **$30K/month safety stock buffer** to absorb 90%+ of unpredictable demand spikes.
